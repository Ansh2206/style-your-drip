Style Your Drip

Style Your Drip is a responsive React-based e-commerce web application for browsing products, filtering products by category, adding products to a shopping cart, managing quantities, and calculating the cart total.

Features

Product listing

Category-based product filtering

Add new products

Add products to cart

Increase/decrease product quantity

Remove products from cart

Dynamic cart total

Empty cart state

Client-side routing

Responsive design for desktop, tablet, and mobile

Tech Stack

React

JavaScript

HTML

CSS

React Router

Vite

How to Run

1. Clone the repository

git clone https://github.com/Ansh2206/style-your-drip.git

2. Navigate to the project folder

cd style-your-drip

3. Install dependencies

npm install

4. Start the development server

npm run dev

Open the local URL provided by Vite in your browser.
