# Style Your Drip

Style Your Drip is a React-based e-commerce web application that allows users to browse products, filter products by category, add products to the cart, manage quantities, and calculate the cart total.

## Features

- Product listing
- Product category filtering
- Add new products
- Add products to cart
- Increase/decrease cart quantity
- Remove products from cart
- Dynamic cart total
- Empty cart state
- Client-side routing
- Responsive design for desktop, tablet, and mobile

## Tech Stack

- React
- JavaScript
- HTML
- CSS
- React Router
- Vite
